Group of strings → records (using enumerate()) → DataFrame (using pd.DataFrame()) → trim whitespace (using str.strip()) → remove empty texts (using .ne("") and .loc[]) → remove duplicates (using drop_duplicates()) → CSV / JSON files (using to_csv() / to_json())

Labeled text records → DataFrame (using pd.DataFrame()) → separate text and labels (using df["text"] and df["label"]) → numerical text features (using TfidfVectorizer().fit_transform()) + target array (using to_numpy())

Document → words (using split()) → overlapping chunks (using list slicing and " ".join()) → records with IDs and source metadata (using enumerate() and dictionaries) → chunk texts (using list comprehension) → NumPy embedding matrix (using model.encode(..., convert_to_numpy=True))

Group of strings → token IDs (using tokenizer()) → fixed-length sequences (using padding="max_length", truncation=True, and max_length) + attention masks (generated by the tokenizer) → PyTorch / TensorFlow tensors (using return_tensors="pt" / return_tensors="tf")
